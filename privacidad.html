Privacidad.

Este sitio pertenece al Instituto Nuestra Señora de la Merced de Arroyito, Córdoba. La información enviada mediante formularios se utiliza para gestionar la consulta o trámite solicitado y comunicarse con la persona correspondiente.

El sitio no solicita datos personales innecesarios para la navegación. Cuando un formulario requiera información, se indica qué datos son necesarios para poder procesar la solicitud.

Para consultas sobre el tratamiento de datos o sobre una solicitud enviada desde este sitio, podés comunicarte con la institución desde la sección Contacto.
